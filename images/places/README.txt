PLACE PICTURES
==============
Drop a picture in this folder named after the place type, as .webp or .jpg
(16:9 landscape, about 1200 x 675 px, under ~150 KB).

A card uses the most specific match: e.g. a Cottage looks for cottage, then houses, then residential-settings.
So you can send a few broad ones (the top-level groups) and add specific ones over time.

Included pictures: one per top-level group and per type.
Types with no picture of their own show a default map pin that is drawn in the current theme colours (no file needed).
To give a single type its own picture (e.g. cottage.webp), just add it here.

Same-named types under different parents (e.g. School > Classroom vs College > Classroom):
name the picture "<parent>-<type>.webp" (college-classroom.webp) to give the one under that
parent its own picture; plain "classroom.webp" is used for the others.
